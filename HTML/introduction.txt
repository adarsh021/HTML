* Stands for hyper text markup language
* Used to create structure of web pges.
* Also know as skelten of web page.
* A single html doc is know as web pages.
* invented by "TIM- BERNERS LEE" in 1991. at wwwconsortium(cern)
* Hyper text : it refers to an text on web page which is link internaly together with another web page.
* Markup lan : it is an high level lang, use to create structure of web page using tags.
* Curent version of html is html5.
* currenty html lang is maineging by WHATWG(Web hypertext application technology working grouping).
